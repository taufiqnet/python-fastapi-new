Step-by-Step Installation & Usage Guide

                
How to run and connect this read-only MCP server with Claude Desktop or Claude Code.

            

        


        


            
            

                

                    1
                

                

                    
Install MCP SDK Dependencies

                    
Install the Python MCP SDK using the isolated dependency footprint in app/mcp/requirements.txt:

                    

                        pip install -r app/mcp/requirements.txt
                        
                    

                

            


            
            

                

                    2
                

                

                    
Configure Acting User & Environment

                    
Set the MCP_ACTING_USER_ID environment variable to a valid database User ID to enforce RBAC permissions and tenant scoping:

                    

                        export MCP_ACTING_USER_ID={{ current_user.id }}
                        
                    

                

            


            
            

                

                    3
                

                

                    
Run stdio Transport Server

                    
Launch the MCP server entrypoint in stdio transport mode:

                    

                        python -m app.mcp.hr_report_server
                        
                    

                

            


            
            

                

                    4
                

                

                    
Claude Desktop Configuration

                    
Copy this configuration snippet into your claude_desktop_config.json:

                    

                        
{
  "mcpServers": {
    "hr_payroll_reports": {
      "command": "python",
      "args": ["-m", "app.mcp.hr_report_server"],
      "env": {
        "MCP_ACTING_USER_ID": "{{ current_user.id }}",
        "DATABASE_URL": "sqlite:///./app.db",
        "APP_ENV": "production"
      }
    }
  }
}
